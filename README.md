# SakhiPlus.
Sakhi+ is a simplified safety application that brings commonly used emergency features into a single, minimal interface. the project focuses on reducing complexity during emergencies by offering easier ways to trigger help, such as a manual SOS, voice activation, and phone shake detection. The MVP also groups essential safety utilities—trusted contacts, guardian mode, community alerts, and evidence recording—into one place, allowing users to access them quickly without navigating multiple screens. The current version prioritizes usability and response simplicity rather than feature expansion. Future improvements aim to make the system more reliable in real-world situations by enabling offline operation and improving location tracking, especially in areas with poor connectivity.
